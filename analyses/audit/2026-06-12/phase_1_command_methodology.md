## 2. Ranked findings

### P0-1 (F1). `uw insights signal-confluence` is a re-count of already-scored lines, leveraged 4× in one decision chain
Live probe: the tool returns per-ticker `factors: [bullish_flow, low_pcr, volume_spike, dp_accumulation, oi_building, low_iv_cheap_options]` — i.e. **server-side re-aggregation of the same quantities the rubric already scores** (+3 accum, +1 OI-build, +1 cum-flow). It is used as (1) the Step-0 funnel seed, (2) the Step-3 entry gate, (3) the +2 "second-agent confirmation" scored line, (4) a 3-of-5 LB-gate member. A name with the accumulation stack lit has ≥3 of 6 factors lit by construction — the +2 is near-deterministic, not confirmation. The "+19.5pp marginal (n=12)" that justified its 2026-05-23 promotion is selection-confounded (candidates funnel-seeded and gate-admitted on the same score). Sub-findings: (a) weekly internal drift — entry gate ≥5, rubric line ≥4, quant told `min_score=5` (a 4-scoring name is undecidable as instructed); (b) the CLI has **no per-ticker mode** (`--date/--direction/--min-score/--top-n` only) — "run per ticker" is unimplementable, candidates outside the returned top-N silently read as no-confluence; (c) the composite is magnitude-blind (binary factor counting; live sample: a 6-factor name with ~$250K net flow outranks 3-factor names with $100M behind them); (d) its `low_pcr` factor *rewards* the crowding the −2 contrarian line penalizes, bypassing the C13 router.

### P0-2 (F2). The sizing ladder's input — `uw historical signal-backtest` — cannot deliver what the commands and quant spec demand
Live-verified, fully reproduced: (a) **forward windows silently clamp to the latest bar** — "5-day" wins on fresh signals are graded at current spot on 2–3-day unresolved windows (recency masquerading as history; cross-verified against `uw historical trend` closes); (b) the quote is **unstable under `--top-n`** — same class/window returned WR 55.6% vs 49.3% across pagination choices, i.e. **across the 0.50 sizing boundary**; (c) **no `--symbol` flag exists** — "per ticker, per signal class" is unimplementable as written, and the 2026-06-11 production envelope confirms one market-wide class statistic stamped onto every ticker (sometimes under a *different* class label than queried); (d) the flagship `dark_pool_accumulation` class **always returns empty** → permanently routes to the fallback proxy, which is circular (grades the system's own post-gate top-5 survivors), hindsight-reconstructed (watchlist stores tickers only — direction and class re-inferred while looking at the outcome), and pseudo-replicated (repeat picks recounted in n). The entire calibration edifice (ladder, caps, excess gate) post-processes this number. The humility caps (0.69/0.80) limit the damage *magnitude* but the *ranking* information content of `win_rate` is close to nil at n=0–10. `[memory-contamination risk: none — all probed live this session.]`

### P0-3 (F3). Additive confluence still counts one actor's footprint up to ~13 daily / ~16 weekly points
One whale building one position fires DP prints → OI build → premium accretion → dealer DEX response → multileg structure → confluence composite as a *causal cascade*, not independent confirmations. Daily: +3 accum + +1 OI + +1 cum-flow + +2 confluence + +3 DEX + +2 multileg + +1 sector ≈ 13 vs HIGH ≥ 9; the conservative core (accum+OI+flow+confluence+DEX) = 10 still clears HIGH. All five LB-gate tools are downstream of the identical footprint, so the gate measures *citation breadth*, not *evidence independence*. C11/C13/LB are real but local mitigations; none imposes cross-*quantity* independence. (b) Weekly is worse: OI is scored ≈3× (+3 standalone, inside the +3 accum conjunction, inside the confluence `oi_building` factor, plus +2 rolls on LEAP names) — and the 2026-05-09 daily demote rationale ("correlated with the LOAD-BEARING components", +2→+1) was never propagated to the weekly +3. (c) cum_premium_flow_30d is one scalar driving five mechanisms (accum-conjunction confirmer, +1 own line, sector-leader conditions b/c, flow_conflict trigger, tie-breaker) — a ±4-point swing from one datum the system's own audits grade NO-INFO standalone. Note the C2 excess gate caps *size* of beta-longs but tier labels, Exec-Summary placement, watchlist write-back, and deep-dive hand-off all key on the raw additive score — those channels are uncontained.

### P1 (F4). Rubric weights are fitted to statistical noise, one regime, with look-count ≫ data
